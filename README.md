# FRATERNITAS-ERP

Sistema integral de gestión administrativa, financiera y documental para la **Respetable Logia Simbólica Fraternidad No. 1**, desarrollado bajo la metodología **SIGLUX**.

---

## Objetivo

FRATERNITAS-ERP tiene como finalidad centralizar y optimizar los procesos administrativos de la Logia mediante una plataforma web segura, robusta y escalable, sustituyendo el uso de hojas de cálculo como herramienta principal de gestión.

El sistema está diseñado para garantizar la integridad de la información, facilitar la administración institucional y proporcionar una única fuente de información confiable para todos los procesos de la Logia.

---

## Principios del proyecto

* Una única fuente de verdad para la información institucional.
* Desarrollo incremental y verificable.
* Arquitectura modular y escalable.
* Código limpio, mantenible y documentado.
* Validación funcional antes de integrar cualquier cambio.
* Trazabilidad completa mediante Git y documentación técnica.

---

## Arquitectura tecnológica

* **Lenguaje:** Python 3
* **Framework:** Django
* **Base de datos:** SQLite (versión inicial)
* **Control de versiones:** Git + GitHub
* **Metodología de desarrollo:** SIGLUX

## Alcance de la primera versión

La versión inicial contempla el desarrollo del módulo de Tesorería, incluyendo:

* Autenticación de usuarios.
* Administración de miembros.
* Migración de datos históricos.
* Registro de ingresos.
* Registro de egresos.
* Generación de recibos.
* Reportes financieros básicos.
* Respaldo de la información.

---

## Filosofía de desarrollo

Todo componente desarrollado deberá cumplir el siguiente ciclo antes de considerarse terminado:

1. Diseño.
2. Implementación.
3. Pruebas técnicas.
4. Validación funcional.
5. Integración.
6. Documentación.

Ninguna funcionalidad será incorporada a la rama principal sin haber sido previamente probada y validada.
